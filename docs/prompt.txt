https://arxiv.org/pdf/2603.16461

3D Video Object Detection
Xhuman: <image><image><image><image>. . .
Detect the 3D bounding boxes in the camera coordinate system of the first
frame.
Output a JSON list where each entry contains the object name in "label" and
its 3D bounding box in "bbox_3d".
The 3D bounding box format should be [x_center, y_center, z_center,
x_size, y_size, z_size, yaw, pitch, roll].
Xgpt:
```json
[
{"label": "table", "bbox_3d": [0.32, 0.6, 1.05, 0.86, 1.7, 0.87,
-1.34, 1.08, -2.84]},
...
]
```


My prompts:

  Object counting:
  To count, count the lines whose label is exactly the category asked about.

  Object size estimation:
  The longest dimension of an object is max(dx, dy, dz) of its box, in meters; multiply by 100 for centimeters.

  Absolute distance:
  Measure the distance between the closest points of the two boxes. Treat each box as axis-aligned with half-sizes hx = (|dxcos(yaw)| + |dysin(yaw)|)/2 and hy = (|dxsin(yaw)| + |dycos(yaw)|)/2 along x and y, and hz = dz/2 along z. For each axis the gap is max(0, |difference of centres| - (half-size of one + half-size
  of the other)); the distance is sqrt(gap_x^2 + gap_y^2 + gap_z^2). If a category has several instances, use the closest pair.

  Relative distance:
  Compute, for every candidate, the distance between the closest points of its box and the target's box: treat each box as axis-aligned with half-sizes hx = (|dxcos(yaw)| + |dysin(yaw)|)/2, hy = (|dxsin(yaw)| + |dycos(yaw)|)/2, hz = dz/2; per axis gap = max(0, |difference of centres| - sum of half-sizes); distance =
  sqrt(gap_x^2 + gap_y^2 + gap_z^2). For a category with several instances use its closest instance. Then compare the distances.

  Room size estimation:
  The room size is its floor area in square meters, measured in the x-y plane (z is height and is not used). Estimate the walls from the horizontal extent of the objects: the room spans at least from the smallest to the largest x and y reached by the box edges (centre -/+ half the horizontal size), and furniture
  usually stands along the walls.

  Relative direction:
  Work in the x-y floor plane with the box centres. Standing at the centre A of the object you stand by and facing the centre B of the object you face, let f = B - A and, for the queried object C, v = C - A. cross = f_xv_y - f_yv_x: positive means C is on your left, negative on your right. dot = f_xv_x + f_yv_y:
  positive means C is in front of you, negative behind. The angle between f and v is acos(dot / (|f| |v|)); C is behind you ('back') when it is at least 135 degrees.

  Route planning and appearance order:
  No line is added.
