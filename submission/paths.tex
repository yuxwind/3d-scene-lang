\section{Data locations}
\label{sec:paths}

\paragraph{SAM~3 + VGGT-SLAM boxes for VSI-Bench.}
All files below are on the machine \texttt{gandalf}. Each list file holds all 5,130 VSI-Bench questions, one per line;
each question carries the SAM~3 boxes of the objects it names (question-name prompts plus ``room door'' and
``radiator''), box score $\geq 0.7$, in the frame of the first camera. Table~\ref{tab:paths-s3} gives the files.
The list files are in \path{/scr/xinyu/projects/3d-scene-lang/data/scenelang_vsibench_slam/}.
The raw per-scene output (VGGT-SLAM reconstructions, SAM~3 masks, and the boxes for each prompt variant; 119\,GB)
is in \path{/scr/xinyu/projects/VGGT-SLAM/exps/vsibench_objects/all/}.
